# system keeps working. Vanilla MAA remain recruitable for now — these are

# Localization deferred — "Loc intent" comments carry the intended names.

# Counter web (vanilla types):
#   skirmishers > heavy_infantry   archers > skirmishers
#   light_cavalry > archers        pikemen > cavalry
# ─────────────────────────────────────────────────────────────────────────────
