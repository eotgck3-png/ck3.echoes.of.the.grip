# ── eotg_event_backgrounds.txt ──────────────────────────────────────────────
# Mod-owned event backgrounds: docs/specs/event_quality_v1.md §14.1 (W2).
#
# Each key is one background block copied from the cited vanilla fallback entry in
# game/common/event_backgrounds/01_event_backgrounds.txt (CK3 1.20.0.3), with no
# trigger, so it resolves the same way for every culture and government (spec §6,
# "Deviation, stated"). Shape: game/common/event_backgrounds/_event_backgrounds.info.
# Events use them as  override_background = { reference = eotg_bg_x }
# (vanilla form: events/dlc/ep3/ep3_admin_events.txt:436).
#
# Every image ships in the base game folder (gfx/interface/illustrations/event_scenes/),
# not in a DLC folder, so no has_dlc_feature fallback is needed.
# The ambience strings name castle rooms; they are audio only (spec W2 risk note).
# The art track (W10) replaces one reference per key.
# ─────────────────────────────────────────────────────────────────────────────
