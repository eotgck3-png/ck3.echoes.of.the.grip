# TEST ONLY: EotG Test: British Isles (docs/test_submods/british_isles/README.md). Never shipped.
# The inert "void" government: one holder per empire OUTSIDE the test zone holds every
# county there, so the vanilla map and titles stay intact (nothing removed, nothing for
# vanilla script to trip on) while no real rulers, courts or barons load out there.
#
# Shape: the main mod's eotg_unclaimed_government (common/governments/
# eotg_unclaimed_government.txt), itself vanilla herder_government without its
# mechanic_type. Differences, on purpose:
#   - its own flag eotg_test_government_is_void, NOT eotg_government_is_unclaimed:
#     the main mod's eotg_unclaimed_game_start_effect would otherwise split every void
#     holder into one Unsworn placeholder per county (~4,400 rulers);
#   - no can_get_government: the owner chose mortal void holders whose heirs the engine
#     picks or generates (2026-10-08), so an heir must be able to take the government
#     (use_as_base_on_landed + sticky_government below, and the on_title_gain safety net
#     in common/on_action/eotg_test_bi_on_actions.txt);
#   - every holding type is valid, because void counties keep whatever capital holding
#     vanilla gave them (castle, city, temple, tribal, nomad, herder, temple citadel).
# War immunity: the sub-mod's copy of herders_and_tributary_constraints
# (common/scripted_triggers/eotg_vanilla_overrides_triggers.txt, generated) reads
# eotg_test_government_is_void on both sides. Mortal holders + no armies + no wars.
