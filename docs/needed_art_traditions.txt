ECHOES OF THE GRIP — NEEDED ART: CULTURAL TRADITIONS
======================================================
Covers all 39 reflavoured tradition IDs.

All tradition icons are placed in:
  gfx/interface/icons/culture_tradition/4-items/
Size: 64x64 px, DXT5 format (with alpha).

Layer reference:
  Layer 0 = background colour (martial / diplo / steward / learning / intrigue)
  Layer 1 = pattern (western / mena / indian / mediterranean / default1)
  Layer 4 = item icon (the .dds file listed below)

"KEEP" = reuse vanilla layer as-is.
"CHANGE" = vanilla layer wrong for the setting; needs override.
"NEW ICON" = required new .dds asset.
