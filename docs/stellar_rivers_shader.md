# Space map presentation: rivers, ocean, and the cheap-wins pass

Rivers are rendered as self-illuminated "stellar wind" energy lanes instead of water; the sea is rendered as deep void with an energy shoreline. Gate 4 (presentation) work, built and tested standalone 2026-09-21 against CK3 1.19.0.6; brought into the main tree the same day. It has no dependency on titles or `map_data/` beyond the river mesh the engine builds from `rivers.png`.

## Files
| Path | Role |
|---|---|
| `gfx/FX/river_surface.shader` | Full-file override of vanilla. Custom vertex shader (`VS_eotg`) widens the river ribbon 2.5x for a glow halo; pixel shader (`PS_surface`) composes halo + core line + three wandering filaments + fast wisps; additive blend (`EotgAdditive`). |
| `gfx/FX/river_bottom.shader` | Full-file override. Discards the riverbed pass (`clip(-1)`), so nothing is written to the refraction buffer. |
| `gfx/map/rivers/rivers.settings` | Vanilla keys; feeds the `JominiRiver` constant buffer. Runtime-tunable, no recompile. |
| `gfx/map/rivers/riverwater.settings` | Vanilla copy with `FoamRampTexturePath` pointed at the lane ramp (side effect: ocean foam tint uses the same ramp, normally invisible). |
| `gfx/map/rivers/eotg_lane_ramp.dds` | 256x1 uncompressed 24-bit RGB, no mipmaps. Left = hue 0, right = hue 1; starts and ends on the same colour so `frac()` wrapping is seamless. |
| `docs/assets/eotg_lane_ramp.png` | Editable source for the DDS. |
| `gfx/FX/pdxwater.shader` | Full-file override (ocean + lakes, normal and low-spec paths). `EotgVoid()` = near-black base + slow nebula drift tinted from the ramp + thresholded-noise stars. `EotgShore()` = gaussian rim at Depth 0, exponential glow seaward, bands rolling toward land (vanilla wave shape, re-coloured, broken up along the coast by noise), shallow wisps. Depth = water height - terrain height per pixel, as vanilla. Map-mode colour overlay, fog of war, distance fog and flat-map blend kept verbatim. |
| `gfx/map/water/water.settings` | Vanilla copy with `FoamRampTexturePath` pointed at the lane ramp (the ocean binds its textures here, not in `riverwater.settings`). |
| `gfx/particles/ocean_birds.particle2` | Vanilla copy with `max_particles=0`, `emitter_enabled=no`. The engine spawns this via a hardcoded `coastal_land` entity (`gfx/models/_env_entities.asset`) on coastal provinces; there is no script-side hook, so disabling the particle is the only clean off-switch. Vanilla has no other ambient sea life; ships at sea are embarked armies (unit models, gameplay), untouched. |

| `gfx/map/map_object_data/*.txt`, `generated/*.txt` | 27 vanilla files with every object set to `count=0` / `transform=""`: trees, reeds, bushes, animals, cliffs, bridges, mist/snow/desert/waterfall effects, landmark décor (Hadrian's Wall, Great Wall, Constantinople sprawl). Holdings, special buildings, unit/siege/combat locators, lakes and map-table décor are untouched. Placements are vanilla-map specific anyway; when the mod ships its own `map_data/` these files should simply not exist rather than be zeroed. |
| `sound/map/ambience/terrain_ambience_layer_default.txt` | Emptied: vanilla maps every terrain type plus ocean/river to the nature `masterAmbienceSystem` FMOD event (birds, waves, wind). Holding ambience (city/castle hum) comes from 3D emitters on buildings via `sound_alias_bank.txt` and is untouched. |

## Cheap-wins pass (2026-09-21)
| Path | Role |
|---|---|
| `gfx/FX/clouds.fxh` | `GetCloudShadowMask()` returns 0 (both signatures kept): no drifting cloud shadows anywhere. |
| `gfx/map/environment/environment.txt` | Colour grade: cool white sun, fog colour black-purple instead of blue haze, slightly darker exposure, more contrast, bloom raised (0.5 -> 0.9) with a higher threshold so only emissive things bloom. `MOD(eotg)` marks each changed line. |
| `gfx/map/environment/environment_eotg_table.txt` + `gfx/map/table_styles/table_styles.txt` | Single table style for the zoomed-out chart, replacing the fire-lit western/CE/EP3/TGP tables. |
| `gfx/map/map_object_data/map_table_*.txt` | Physical table props zeroed. |
| `common/defines/eotg_space_map_defines.txt` | `NFogOfWar`: ALPHA_MIN 0.5 -> 0.18, less pattern, less grey wash, darker. Partial define file; vanilla keys not listed keep their values. |
| `gfx/map/borders/*.dds` (35) | Holo-line strips generated by `docs/tools/build_space_textures.py`: thin bright core + soft halo, colours keep vanilla semantics (realm gold, own realm purple, war crimson, ally teal, selection gold-white dashed, impassable crimson dashed, epidemic emerald...). Uncompressed A8R8G8B8 with a mip chain. `pdxborder.shader` untouched. |
| `gfx/map/movement_arrows/*.dds` (14) + `gfx/FX/arrow.shader` | Glowing arrow atlases (same layout: shaft left, head right, travelled bottom) in gold / crimson / violet / teal, and a vanilla shader plus a pulse of light travelling along the path (`MOD(eotg)` block). |
| `gfx/map/terrain/flat_maps/flatmap.dds` + `gfx/FX/paper_transition.fxh` | Star-chart paper map (4608x2304, uncompressed 24-bit, ~32 MB): dark slate land with mottling, black sea with stars, gold-lavender coastlines. Built from the vanilla paper map's land/sea; regenerate from the mod's own map later. The torn-paper wipe is now a plain cross-fade. `pdxwater.shader` no longer blends to the flat map, so the void stays live at strategic zoom. |
| `gfx/particles/forest_birds_01.particle2`, `geese_*.particle2` | Emitters off, as for ocean_birds. Forest terrain spawns forest_birds_01 via `common/terrain_types`. |
| `gfx/FX/dynamic_masks.fxh` | Vanilla with the four snow/frost entry points early-outing: no snow on terrain, meshes, decals, trees. Winter gameplay untouched. |
| `gfx/FX/province_effects.fxh` | Vanilla with the effect sampler returning zero: no drought / flood / dry-summer / snow province visuals. Epidemic visuals (`disease.fxh`) deliberately kept. |
| `map_data/seasons.txt` | Vanilla four seasons only; the `tree_*` foliage-colour seasons removed (no trees). Single-file override; folds into the mod's own map_data later. |
| `gfx/FX/surroundmap.shader` | Beyond the map edge: black with faint twinkling stars instead of parallax clouds / paper table. |

Deferred from that list: **skybox**. It needs a `.mesh` cube asset plus a cubemap and a `pdxmesh.shader` effect; terrapass/ck3-modutil-skybox shows the method but has no license to vendor, and hand-written PDX binary meshes are not something to ship untested. With the default camera pitch the sky is barely visible anyway; revisit if the camera is unlocked.

Regenerate all generated textures with: `python docs/tools/build_space_textures.py <mod root>` (needs Pillow + numpy; reads the vanilla flat map from the Steam install).

## Tunables
Rivers: all `#define EOTG_*` at the top of `PS_surface` (and `EOTG_WIDEN` in `VS_eotg`). Ocean: the `EOTG_*` block in `pdxwater.shader` (`EOTG_VOID_COLOR`, `EOTG_NEBULA_*`, `EOTG_STAR_*`, `EOTG_SHORE_RIM_*`, `EOTG_BAND_*`); the hue scheme mirrors the rivers so the two match. Key river ones:
- `EOTG_PALETTE` — 0 gold, 1 purple, 2 cosine palette (`EOTG_PAL_A/B/C/D`, Inigo Quilez form), **3 ramp texture (shipped default)**.
- `EOTG_HUE_SPREAD` / `EOTG_HUE_REGION_SCALE` — how far and how fast the hue wanders across the map; filaments and wisps take their own offsets.
- `EOTG_ALONG_SCALE`, `EOTG_FLOW_SPEED`, `EOTG_FILAMENT_LENGTH`, `EOTG_WISP_LENGTH` — streak scale and speed along the river.
- `EOTG_KEEP_WHEN_ZOOMED_OUT` — 1 disables vanilla's zoom-out fade.

## Regenerating the ramp
Give the colour stops to the orchestrator, or edit the PNG and export as uncompressed 24-bit DDS with no mipmaps under the same name. The DDS header must match vanilla `gfx/map/water/foam_ramp.dds` (24 bpp, masks R=0xff0000 G=0xff00 B=0xff, caps 0x1000).

## Debugging
Shader compile failures are silent in-game (rivers simply do not draw; the carved terrain channel shows through). Look in `Documents/Paradox Interactive/Crusader Kings III/logs/error.log` for `Compile error` / `Failed getting shader for PS_surface`; the HLSL error and line follow. HLSL reserved words (`line`, `point`, `sample`, `texture`, `matrix`, `vector`, `half`) cannot be variable names — `line` cost one round of testing.

## Maintenance
- Overrides replace the whole vanilla file: after a CK3 patch, re-diff against `game/gfx/FX/river_surface.shader`, `river_bottom.shader` and `pdxwater.shader`, plus the two `.settings` files and the particle. Every deviation from vanilla is marked `MOD(eotg)`.
- Conflicts with any mod that also overrides these three shaders.
- The standalone test copy lives at `Documents/Paradox Interactive/Crusader Kings III/mod/eotg_stellar_rivers/` and is the harness until the v2 tree has a `descriptor.mod` (Gate 0). Keep the two in sync or delete the standalone once the main mod loads.
- Advanced Shaders on/off: both paths compile from the same code (no `LOW_SPEC_SHADERS` branch needed yet).
