# art_needed.txt — Echoes of the Grip
# Master list of every custom art asset the mod requires.
# Supersedes the per-system art_needed_* files in docs/.
#
# FORMAT NOTES
#   DXT5  = RGBA (has alpha/transparency)
#   DXT1  = RGB  (opaque)
#   Size is width×height in pixels.
#   All paths are relative to the mod root.
#
# STATUS LEGEND
#   [ ] = not yet made
#   [P] = using vanilla placeholder (game won't crash, but looks wrong)
#   [X] = done
#   [R] = REUSE — see note; no new asset needed
#
# REUSE POLICY
#   Reuse is marked only within the same government type, or for truly generic
#   concepts that have no government-specific character. Cross-government reuse
#   is avoided unless the icon represents a universal, non-stylized concept.
#
#   Tiered modifier series (same concept at increasing severity) should be
#   produced as one base image with 4 tint/state variants, not 4 fully
#   separate paintings. The base is marked [ ], variants marked [R] with notes.
# ==============================================================================
