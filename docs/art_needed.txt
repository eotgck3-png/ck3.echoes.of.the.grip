# ── TECHNICAL NOTES ───────────────────────────────────────────────────────────
# All .dds files must be saved with mipmaps.
# DXT5 for anything with transparency (icons, traits, faith).
# DXT1 for full-bleed opaque illustrations (decisions, events, bookmark).
# Use Intel Texture Works or GIMP DDS plugin.
# See vanilla gfx/ folder for reference examples of each type.
#
# When adding a modifier icon, update the `icon =` field in eotg_modifiers.txt
# from the vanilla placeholder to the new custom key name (without path or .dds).
# When adding a trait icon, uncomment the `# icon = eotg_*` line in eotg_traits.txt.
