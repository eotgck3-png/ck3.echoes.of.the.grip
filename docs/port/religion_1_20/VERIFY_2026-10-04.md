# Local verification of the staged 1.20 religion port (eotg-vanilla-scout, vanilla 1.20.0.3)

**Verdict: the structure is valid.**
- All 23 tenet keys and all 59 doctrine keys resolve in 1.20.
- No unrecognised fields.
- Assumptions A1, A4, A5 and A7 are CONFIRMED.

**Two defects, three missing fields, three behaviour gaps.**

## Converter fix list (for port_religions_1_20.py)
1. **All 4 families: tenet icons.** Replace the `core_tenet_banner_*` mapping and the TODOs with the vanilla set, from `common/religion/religion_family_types/00_religion_family_types.txt:4-7`:
   ```
   tenet_background_icon = tenet_banner_known_core
   tenet_heretical_background_icon = tenet_banner_unknown_heretical
   tenet_neutral_background_icon = tenet_banner_known_neutral
   tenet_unknown_background_icon = tenet_banner_unknown_neutral
   ```
   Why: `core_tenet_banner_christian.dds` does not exist in 1.20. `core_tenet_banner_pagan` exists, but it has no `_small` pair, and the `.info` requires one.
2. **`eotg_rf_divine_order`:** `graphical_faith = "christian_gfx"` is not a vanilla value. Use `"orthodox_gfx"`, which is what `rf_abrahamic` uses. `pagan_gfx` is fine.
3. **Faith `icon`:** emit `icon = <existing vanilla faith icon basename>` per faith, e.g. a pagan one, rather than relying on a fallback. A6 (the no-icon fallback) is unproven, and no `eotg_*` faith textures exist.
4. **Recommended:** emit `doctrine = abrahamic_hostility_doctrine` / `pagan_hostility_doctrine` in each religion, matching its family's `hostility_doctrine`. Vanilla religions all carry one (`00_christianity.txt:10`, `00_paganism.txt:9`). Whether it's required is BEHAVIOUR.
5. **PORT_REPORT.md:** drop the UNVERIFIED-VANILLA marks for A1, A4, A5 and A7. Reword A2 and A3 to the corrected facts. Delete the three sibling-icon TODOs once fix 1 is done.
6. **Holy sites:** when un-commenting, use the list form `holy_sites = { }` / `eminent_holy_sites = { }`, not the old singular `holy_site =`.

## Design call, not a port bug: empty doctrine groups
Vanilla religions fill these doctrine groups, but the v1 religions never did: theism, monasticism, sacraments, coronation, preservation, hostility. Whether an empty group breaks anything is BEHAVIOUR, to settle with an in-game load test. It goes to the human or architect when religions are actually ported (B-FAITHS).
