# event_quality_v1 W3 (outcome surfacing): loc keys the built script references (eotg-scripter, 2026-10-09).
# Spec: docs/specs/event_quality_v1.md W3 and §12 (voice, quotes). Owner of the text: eotg-localizer.
# Target files (UTF-8 with BOM, existing files only): localization/english/eotg_augmentation_l_english.yml,
#   eotg_aug_inherit_l_english.yml (inherit keys), eotg_frontier_l_english.yml (frontier keys). Each key is
#   tagged with its file below.
#
# What these are. Every key is a TITLE only: a send_interface_toast (to root) or a send_interface_message
#   (to the other character named in the note). No desc keys: the engine renders the title line alone.
#   type: good / neutral / bad = event_toast_effect_* (toasts) or send_interface_message[_good|_bad] (messages).
#   Icons are set in script (left = root unless noted; right = the other party). Do not repeat them in text.
# Rules for the text (W3 + §12 + cybernetics rendering rules):
#   - Say what happened, in a short line, the way vanilla toast titles do (e.g. "The Duel Is Won" style, or a
#     short sentence). Canadian English, no dashes, no hardcoded names: use loc scopes.
#   - NEVER a number, odds, chance, or the word "risk"; never name fracture risk, residue, Establishment or any
#     hidden meter. Where a note says "hidden cost/gain", name only the visible symptom (the strain, the scar,
#     the doubt), never the meter. QA greps these keys against the rendering rules.
#   - Toasts to root: first person or neutral (§12.1 rules 1 and 5; short outcome lines may use "you" only
#     where vanilla does). Messages to another character: second person is allowed ("Your liege ...").
#   - Speech, if any, in unescaped straight double quotes (§12.2); never \" and never '...' speech.
#   - The cybernetics register binds (cybernetics_v2.md §5: banned list, licensing never named, "self" not
#     "humanity", no monotheistic invocations, the medieval-leak substitutions, no time-of-day words).
#     The implant never speaks; it is never a second speaker (§12.1 rule 7).
#   - Scopes: the event's saved scopes named in each note are available bare in loc, e.g.
#     [eotg_heir.GetFirstName]; ROOT is the receiver. Never [scope:x...]. If unsure a scope survives into the
#     toast, write the line without it: the right icon already shows who.
# Key form: <event_id>.toast_<option>_<outcome>, <event_id>.toast_<outcome> (an outcome rolled in immediate,
#   surfaced on the resolving option), <event_id>.msg_<...> (messages). Frontier stage toasts follow the file's
#   existing eotg_frontier_toast_* form (they live in a scripted effect, not an event).
# Kingpin (events/eotg_augmentation_kingpin.txt) is DEFERRED from this pass (batch B in flight); its W3 keys
#   will be listed by the Kingpin batch B scripter.
# Not new: existing toasts kept as they were (eotg_aug_tier2.012.a.success_true/_false, eotg_aug_tier3.014.b.toast_*,
#   eotg_aug_tier3.006.e.clean/strained, the *.override_tt family, eotg_aug_forget_relation_toast, ...).
# Total keys: 171 (toasts 147, messages 24)
